# A 股助手 v0.3 交付规格

目标：供非技术用户使用，输出中文、有出处的A股研究。手机路线提供一个可导入并部署的完整云端技能套装，包含12模块、公开原始资料、A股底稿、程序、私有记录模板和版本清单。单段提示词仅为降级。
安装入口：支持 Codex、Claude Code、通用 Agent Skills 目录。安装与 Python 运行环境分别验收；
纯手机聊天不保证能运行本地命令。不接券商、不自动下单，不将研究结论冒充盈利保证。

公开接口验收范围：
1. CLI：doctor / fetch / audit / analyze / news / fundamentals / screen / portfolio / backtest / validate。
2. 数据契约：唯一日期、有效 OHLCV、明确价格口径、来源、哈希、日期范围；缺失不能填为零。
3. 回测 API：上一日收盘信号、下一开盘执行，现金守恒、T+1、交易数量、停牌、方向性涨跌停、成本。
4. 调整价格研究：单独标为 proxy，不冒充实际股数/现金成交；最终留出集不参与选参数。
5. 技能包：各技能独立可发现，安装后可调用共享运行器；不会覆盖用户其他技能。
6. 新闻：实际发布时间和原文链接，新闻不等于公告，外部文本不得控制工具或执行命令。
7. 数据覆盖不足、权限不足、离线均明确报告，不伪造指标或回测。
8. 研究资源清单：记录核读范围、版本、许可和采用决策，保留美股可共用框架。
9. 整合ZIP：全部12模块不丢失、引用可达、原始资料与许可保留、运行器脱离仓库可执行、逐文件哈希可验、同来源构建可复现。
10. 研究记录：显式私有目录、版本与哈希、幂等、交接导出/导入、新进程恢复、篡改/冲突停止并保留原库；不承诺目标云端自动持久化。
11. 方法迁移：已有Notion方法映射到A股模块；未取得本地源码与未实施的高级工具标清，私人原文/持仓不公开。
12. 手机使用：官方上传/部署路线已核，实际账号的发现、执行、网络、依赖、持久保存另验；未部署不叫已上线。
13. 专业覆盖：投资目录13页484项逐项分类，新增5个方法适配；保留34个独立原始资料包，已有10套参考继续保留。完整475模块另存私有扩展备份，不声称全工作区或每项执行通过。
14. 参考读取：归档/源原文/阅读副本分别校验，拒绝停用、越界路径、符号链接、哈希变化和覆盖用户目录；不执行来源脚本或自动授权账户。
15. risk：至少60共同原生相邻收益区间，同一持仓快照、CNY、复权和身份；输出相关性、贡献、历史VaR/ES及口径，缺失不得补零、不得桥接不相同时间区间。
16. financial-audit：6类年度线索，严格披露/口径/行业及缺失状态，不是完整排雷、审计或造假结论。
17. valuation-review：三情景概率、敏感性与反向同倍FCFF，整体DRAFT_REVIEW，不能因数值通过升级为证据/治理PASS。

本轮不实施：全市场 PIT 数据库、自动交易、已验证缠论引擎、训练 LLM、高频行情。
提供这些能力的接入路径、研究技能及独立验收条件，不把未实施模块写成已运行。
