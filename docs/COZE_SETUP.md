# A股家庭助手：一次准备，手机选择技能

推荐承载为扣子已部署的云端技能。妈妈不用代码，家人负责首次导入与验收。本项目未登录目标账号或完成部署，当前交付是可导入包，不是已上线服务。

v0.3分为核心技能ZIP、开发者完整源码ZIP、完整投资参考资料库ZIP。手机导入只选核心技能ZIP；完整资料库含475个来源模块及5项新增原包，不自动安装，不让模型一次读完。新版本覆盖清单见references/coverage.json，不再以一个提示词或475项索引冒充已执行能力。

## 家人准备

1. 下载a-share-family-suite.zip；源码版可运行README的导出命令。不要上传整个开发仓库ZIP冒充单个技能包。
2. 用妈妈自己的账号进入[扣子编程](https://code.coze.cn)，首页选择“技能”→“上传技能包”，上传ZIP。扣子将解析、安全检测、重新打包。[官方上传说明](https://docs.coze.cn/guides_vibe_coding_skill)。
3. 如需适配，将下方导入要求交给扣子编程；保留全部方法与资源，不让它浓缩成总提示词。必要敏感配置用环境变量；没有Tushare权限就用官方公告路径，不能让妈妈提供账户密码。
4. 在预览中完成下面验收；确认后“打包”→“打包技能”→“立即体验”。[官方发布说明](https://docs.coze.cn/guides_deploy_skill)。自定义技能默认仅所有者本人可用，所以不要在你的账号部署后假定妈妈自动能用。
5. 用妈妈手机同一账号核技能是否可见。在新对话中用“➕→技能”或“/→技能”选择“A股家庭投研助手”。[官方使用说明](https://docs.coze.cn/guides_using_skill)。实际手机界面以当前账号为准。

这是部署到扣子对话的路线；仅上传到“编程技能列表”是另一功能，新编程任务需重新添加，不能当已部署。也不依赖电脑一直在线的个人设备技能。

## 导入适配要求（给扣子编程）

> 请把上传的a-share-family-suite作为一个云端技能部署，保留SKILL.md的渐进路由、12个modules、全部references/vendor许可证、scripts/src、records.py、assets模板及来源映射。不要改成单段提示词，不自动启用原始美国市场参考作为另一个执行技能。先逐项列出实际可用文件、Python版本、网络和可选依赖。运行doctor、教学持仓portfolio和教学DCF，再验证记录导出/恢复。核技能在新对话仍可选择。个人记录只能保存到明确可持久的私有位置；临时目录不保证持久时提供交接下载。告诉我当前支持/缺失功能及原因，不能声称未执行的回测、VaR、缠论或付费接口已验证。完成后保留原包版本并记录所有改动与结果。

还须保留新增34个source-archives及其GPL/AGPL/MIT/Apache许可和源代码、references.py、professional-catalog与coverage清单。references.py只能检索/解包，不自动执行上游脚本；BLOCKED模块不得启用。用synthetic-financials和synthetic-valuation-review分别测试初筛/敏感性，risk需真实来源CSV或明确教学夹具。数值工具通过不等于证据审核或盈利通过。

## 预览与手机验收

| 项目 | 方法 | 通过条件 |
|---|---|---|
| 专业资料 | 要求研究一家公司，并显示读取了哪个模块/底稿 | 原始资料与A股方法仍可读，不仅一个提示词 |
| 确定工具 | doctor、assets/examples的portfolio/valuation | 实际输出；示例标教学，不当真实持仓 |
| 数据 | 获取一只A股已收盘日K，audit；新闻依赖另验 | 来源/日期/哈希/失败原因完整，旧数据不叫实时 |
| 记录 | 教学profile保存、导出、新目录恢复 | 版本/哈希一致，确认生产持久存储的实际条件 |
| 新对话 | 关闭旧任务，重新选择助手 | 技能可见且可读；个人资料若未自动加载则使用交接恢复 |
| 权限缺失 | 不配置Tushare、问财报/缠论/VaR | 标缺失并核官方原文，不伪造运行结果 |

联网和可选依赖不保证自动可用，外部API需按官方说明适配。发布方法≠执行环境/准确率验收。当前云端个人资料永久保存、定时新闻推送未实现；不要勾成已完成。

更新：保留旧包、manifest、变更说明，上传新版本再预览/部署；个人记录单独备份。扣子重打包可能改变文件，开发者须对照原始manifest核保留项。

新低代码智能体发布到豆包的旧入口已于2026-07-01下线，见[官方更新](https://docs.coze.cn/recent-updates)。本方案使用扣子云端技能，不承诺自动进入豆包账号。
