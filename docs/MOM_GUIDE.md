# 给妈妈的使用说明

这套助手帮你读懂公司、查消息、比较估值和检查持仓风险。它会解释理由，并告诉你哪些资料还没查到。你可以直接用中文说话，不用记住12个技能的名字。

## 第一次使用

**推荐：请家人先把完整技能包装到你的扣子账号。**

1. 家人按[完整包导入指南](COZE_SETUP.md)上传、预览、部署并验收。专业方法保存在技能包，不用你反复粘贴大段文字。
2. 你在扣子新对话中选择“A股家庭投研助手”，说“帮我看600519”或发需要解释的资料。不用记12个模块，不用运行代码。
3. 让助手显示数据日期、来源和未知项。研究档案需单独保存；如果客户端未验证自动持久化，请家人帮你下载交接文件，以后上传恢复。

目前尚未在你的实际手机账号验收，不能说已经可用。如果暂时只用豆包，旧提示词仅可帮助有限研究，不能替代完整技能安装、资料库与计算工具。

豆包的开发者App Store说明列出联网搜索、语音输入/输出和拍照识图能力：[官方应用页](https://apps.apple.com/cn/app/id6459478672)。这不证明它能导入本仓库或执行Python。

**如果需要程序计算，由家人准备下面的环境：**

把下面这段话交给电脑上有终端权限的Codex或Claude Code：

> 请从 https://github.com/ch-lyu/A-stock-helper 安装A股助手，按README选择适合你的安装目标。运行安装器给出的doctor命令，确认你能发现a-share-assistant。新闻功能需要可选依赖，请按说明安装。财报没有Token时查交易所、巨潮资讯或公司官方原文，告诉我哪些数据查不到。以后用容易理解的中文回答。

具体安装命令在[README](../README.md)。需要Git和Python3.10+。手机里的纯聊天AI如果没有命令执行能力，不能直接完成本地安装；它可以阅读说明和协助查资料，程序计算需要电脑上的执行环境。

第一次讨论买卖或持仓时，告诉AI资金多久不用、用途是什么、出现多少损失会影响生活。不要提供账户密码、验证码或API密钥。

v0.3会先检查财报质量，再讨论估值；还能用已核数据检查组合相关性和历史风险。你只需说“先帮我排雷，再讲估值和我的持仓影响”，不用记工具名。提示“线索触发”不等于认定公司造假；历史VaR不是未来最多亏多少。

## 可以这样问

| 想做的事 | 可以直接复制的话 |
|---|---|
| 看一家公司 | 用A股助手研究600519：它怎么赚钱，最近变化是什么，现在价格需要哪些假设支持？先查原文，讲清主要风险和还缺什么。 |
| 理解新闻 | 查000001最近的消息，分清公司公告、媒体报道和传闻，解释哪些可能影响利润。 |
| 看财报 | 帮我读这份季报，比较营收、归母利润、扣非利润和现金流，说明增长质量；金额单位要写清。 |
| 判断估值 | 给这家公司悲观、基础和乐观三种情景，解释每个假设。资料不足就别算精确目标价。 |
| 检查持仓 | 按我提供的持仓和同一天市值，看看公司、行业和现金比例，哪些风险过于集中？ |
| 每周复盘 | 整理我的观察名单本周发生了什么，哪些买入理由改变了，列出需要继续核实的三件事。 |
| 验证策略 | 先说明策略、样本、成本和基准，再执行验证。保留亏损结果，告诉我是否真的验证了可成交收益。 |

股票代码最好写成`600519.SH`、`000001.SZ`这样的形式。同一个数字可能表示不同交易所的产品，例如`000001.SH`是上证指数，不能和`000001.SZ`混淆。

## 怎么读它的回答

- 先看数据截至哪一天、来源是什么。旧数据不能叫实时行情。
- 把事实、估计和需要等待的信息分开看。新闻链接不能代替公告原文。
- 估值是一组假设的结果；问一句“哪个假设改变会让结论失效？”
- 回测是历史实验。当前发布的简单策略多数未跑赢自己的持有基准，不能当作赚钱承诺。

持仓计算只使用你自己提供的文件，不登录证券账户，不自动下单。示例文件都是教学数据；请让AI在私有目录保存自己的资料。

## 遇到问题

| AI说什么 | 下一步 |
|---|---|
| 没找到技能 | 让它检查安装器输出的路径、重新加载客户端，再确认a-share-assistant可发现。 |
| 缺AKShare | 让它按README在Python虚拟环境安装可选依赖，再用该环境运行命令。 |
| 缺TUSHARE_TOKEN或权限 | 先查官方财报；不要要求AI编造财务数值。当前财报程序接口需要你自己拥有相应权限。 |
| 数据缺失、口径不一致 | 让它保留原因并核查另一来源；不要自动把缺失数据当零。 |
| 只输出均线表 | 那是行情证据。继续要求业务、财报、估值和反方观点，才能形成完整研究。 |

实际测试与回测记录见[验证文档](VALIDATION.md)。

## 完整程序能力如何在手机使用

完整包已携带行情、审计、估值、回测程序和保存工具。扣子导入后需由家人检查云端Python、网络和存储；若环境不足，再由开发者补服务。妈妈无需配置Python或接口。本仓库尚未完成目标云端账号部署。

不能直接按旧教程承诺“扣子创建后发布到豆包”：扣子官方[更新动态](https://docs.coze.cn/recent-updates)说明，2026-07-01已下线新低代码智能体发布到豆包渠道的入口，已发布智能体不受影响。自建服务能否进入某个客户端，需按当时支持的渠道单独验收。
