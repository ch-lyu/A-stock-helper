# 缠论规则卡与独立验收

本包保留研究/审计规则，未内置已验证缠论引擎。Notion提到的本地安装不证明目标环境安装，不用均线伪造笔、中枢和买卖点。

## 证据

理论定义、实现版本/参数、平台显示三层分开。COMPUTED须已收盘OHLCV、实际输出和可复现配置。截图最多OBSERVED，仅当前价格是条件情景。sure/done/实线不保证不撤回/移动。

| 结构 | 必核区别 |
|---|---|
| 包含 | 先定方向再合并；向上高低都取较高，向下都取较低，顺序影响结果 |
| 分型 | 三根处理K线中间高低极值；右侧未收盘仍形成中 |
| 笔 | 新旧定义、独立K线计数、间隔、端点/确认规则冻结，不称唯一标准 |
| 线段 | 特征序列、包含/缺口、确认规则，不能三个端点便认定 |
| 中枢 | 同级次级走势重叠，ZD=max(low)、ZG=min(high)，核重叠、外围DD/GG另记；不一律三笔代替递归 |
| 级别 | 日/周时间框架为代理，不自动递归级别 |
| 背驰 | 走势段、趋势/中枢背景、力度/确认；MACD面积仅辅助，缩柱不是充分证明 |
| 三买/卖 | 离开有效中枢后回试不跌破ZG/不越ZD及确认；任意突破反抽不是三买卖 |

无有效中枢则写未确认。平台BI/XD/ZSD/PZ/QS、L2B/L3B与引擎1/1p/2/2s/3a/3b语义不同，逐项映射保留未映射，不能强行等价。

## 验收

1. 核安装、版本、许可、数据和所有实际生效参数；调用参数可能未被实现使用。
2. 完整闭合K线逐前缀回放，记录端点日、首次可观察/确认日、撤回/移动；起点已有对象标左截断。
3. 同引擎全量/增量、同口径多源、平台对照定位首次分歧；不通过不靠改名变通过。
4. 最终图低点日不能回填当时信号，回测只用当时确认的信息加A股成交约束。
5. 结构复现、前视/重绘、样本外净收益分别验收；结构通过≠赚钱≠实盘可成交。

120日/40周输入可为本地质量阈值，不是原文理论数字。不复制整本书/PDF或未经授权的平台输出，公开候选见adoption-map。
